# Finder стендов Giga Cowork

Скрипт для поиска стендов (`config.yaml`) в Git-репозитории `argocd` по `cowork_subdomain`, `admin_email`, `ИНН` или `stand_name`. Скрипт автоматически обновляет репозиторий, рекурсивно ищет конфиги в заданных зонах и выводит информацию о найденных стендах, а также предоставляет быстрый доступ к связанным инструментам.

**Репозиторий:**  
[https://git.sberdevices.ru/gigabb/sdb_support/finder](https://git.sberdevices.ru/gigabb/sdb_support/finder)  
Клонирование: `git clone git@git.sberdevices.ru:gigabb/sdb_support/finder.git` или `https://git.sberdevices.ru/gigabb/sdb_support/finder.git`

---

## Возможности

- **Поиск стендов** по одному или нескольким критериям:
  - `cowork_subdomain`
  - `admin_email`
  - `ИНН`
  - `stand_name`
- **Вывод полной информации** о найденных стендах (папка, зона, `stand_name`, `cowork_subdomain`, `admin_email`, ИНН, `expiry_date`, `cowork_revision`, признак `[broken stand]`).
- **Интерактивное меню** после выбора стенда:
  1. Открыть Admin Helper и ArgoCD
  2. Зайти на тенант (`https://<subdomain>.cowork.ru`)
  3. Открыть консоль тенантов (`https://tenant-console.cowork.ru/`)
  4. Запустить FAQ-агента (открывает страницу агента)
  0. Вернуться к поиску
- Автоматическое обновление локального репозитория `argocd` перед поиском.
- Сохранение изменений, появившихся в репозитории после последнего обновления, в папку `news/` (для аудита).

## Требования

- Python 3.6+
- Git (установлен и настроен)
- Доступ к репозиторию `git@git.sberdevices.ru:gigabb/infra/cowork/argocd.git` (SSH или HTTPS) – **этот репозиторий остаётся корпоративным** и используется скриптом для поиска стендов.
- Локальная папка `~/Documents/Giga/cowork/argocd` (по умолчанию) или измените путь в переменной `REPO_PATH` в скрипте.

## Алгоритм работы:
Обновление репозитория argocd:
Выполняется git fetch и git pull origin master.
Если появились новые изменения, они сохраняются в папку news/ в виде датированных diff-файлов.
Выводится список изменённых файлов с их cowork_subdomain (если удаётся извлечь).

---

## Запрос критериев поиска:
Введите значения для полей (можно оставить пустыми, но хотя бы одно должно быть заполнено):
cowork_subdomain
email
ИНН
stand_name

---

## Поиск:
Скрипт рекурсивно обходит зоны cce-prod-tb01 и cce-prod-st02 в поисках файлов config.yaml внутри папок, начинающихся с cowork-.
Для каждого найденного конфига извлекаются все необходимые поля.
Сравнение с критериями происходит без учёта регистра (кроме ИНН).

---

## Вывод результатов:
Выводится список всех подходящих стендов с подробной информацией.
Если найден только один стенд, он выбирается автоматически; если несколько – предлагается выбрать номер.

---

## Меню действий для выбранного стенда:
text
Выбрать действие
  1. Открыть Admin Helper и ArgoCD
  2. Зайти на тенант
  3. Открыть консоль тенантов
  4. Запустить FAQ-агента
  0. Вернуться к поиску
При выборе любого пункта (кроме 0) соответствующая страница открывается в браузере, после чего меню снова отображается – можно выполнить несколько действий подряд.
Выбор 0 возвращает к вводу критериев поиска.

---

## Примечания
Скрипт не изменяет файлы конфигурации – только читает их.
Все изменения в репозитории argocd, появившиеся после последнего pull, сохраняются в папку news/ для отслеживания.
Для работы необходимо, чтобы репозиторий argocd уже был клонирован по указанному пути.
Если зоны (cce-prod-tb01, cce-prod-st02) не найдены, скрипт завершится с ошибкой.
Меню действий остаётся активным после каждого выбора, позволяя выполнить несколько действий без повторного поиска.
